# Favorite Place — Design System

## 1. Дизайн-концепция: «Уютный журнал воспоминаний»

Приложение — это **личный офлайн-дневник** кафе и ресторанов, а не агрегатор доставки. Интерфейс должен передавать ощущение:

- **Тепла и уюта** — как записная книжка, которую приятно открыть
- **Визуальной «дороговизны»** — через продуманные отступы, мягкие тени, скругления, внимание к типографике
- **Ненавязчивости** — фотографии еды и воспоминания в центре, UI отступает на второй план
- **Мобильности** — всё заточено под iPhone, одноручное использование, быстрый ввод

Ключевые принципы:
- **Содержимое важнее обрамления** — минимум границ, максимум воздуха
- **Мягкость** — скруглённые углы, плавные переходы, никаких резких контрастов
- **Консистентность** — все экраны говорят на одном визуальном языке

## 3. Типографика

- **Шрифт**: `"Segoe UI", Tahoma, Geneva, Verdana, sans-serif` — системный, хорошо читается на iOS и Android
- **Заголовки страниц**: 24–28px, weight 600, line-height 1.2, цвет `#2C2926`
- **Заголовки карточек**: 18–20px, weight 500, line-height 1.3
- **Основной текст**: 16px, weight 400, line-height 1.5, цвет `#2C2926`
- **Подписи/метаданные**: 14px, weight 400, line-height 1.4, цвет `#7A7269`
- **Мелкий текст**: 12–13px, weight 400, цвет `#7A7269`

---

## 4. Отступы и сетка

- **Базовый модуль**: 4px
- **Внутренние отступы карточек**: 20px
- **Отступ между карточками**: 16px
- **Внешние отступы контейнера**: 16px по бокам
- **Скругление карточек**: 12px (современно, но не «игрушечно»)
- **Скругление кнопок**: 24px (пилюлевидные, уютные)
- **Скругление полей ввода**: 12px
- **Тень карточек**: `0 1px 3px rgba(44,41,38,0.04), 0 4px 12px rgba(44,41,38,0.06)` — мягкая, «парящая»

## 5. Изменения по экранам

### 5.1. Список мест (`PlacesFeedPage`)
- Карточка места: белый фон, border-radius 12px, мягкая тень
- Градиент вместо сплошного цвета под заголовком: `linear-gradient(180deg, rgba(44,41,38,0.60) 0%, rgba(44,41,38,0) 100%)`
- Категория и название — поверх фото снизу, белый текст
- Рейтинг — звёзды терракотового цвета с золотым fill
- Дата последнего визита и количество визитов — компактно, вторичным цветом
- Список: вертикальный scroll, gap 16px

### 5.2. Карточка места (`PlacePage` + `PlacesInfo`)
- Заголовок с категорией и адресом — крупно, с иконками (`MapPin`, `Tag`)
- Средний рейтинг — звёзды + цифра, крупно
- Список визитов: компактные карточки с датой, рейтингом, превью фото
- Каждый визит — кликабельная строка с левой иконкой `Calendar`, центральной датой и правым рейтингом

### 5.3. Страница визита (`VisitPage`)
- Заголовок с датой и названием ресторана
- Рейтинг визита — крупные звёзды
- Фотографии — горизонтальный scroll (snap) с закруглёнными углами
- Компаньоны — иконка `Users` + список тегами (пилюльки)
- Заметки — отдельная карточка с иконкой `MessageSquare`
- Блюда — карточки: название, рейтинг звёздами, личные заметки о блюде

### 5.4. Добавление визита (`NewVisitFormPage`)
- Шаги оформлены как карточки: «Ресторан», «Детали визита», «Блюда», «Фотографии»
- Поля ввода — белый фон на кремовом фоне страницы, скругление 12px
- Кнопки действий — терракотовые, пилюлевидные (border-radius 24px)
- Выбор блюда — превращается в теги с рейтингом и заметкой
- Фото — сетка 2×2 с возможностью удаления
- Сохранение — кнопка «Сохранить визит» на всю ширину, внизу экрана
