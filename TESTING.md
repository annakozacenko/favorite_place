# Чеклист тестирования Favorite Place

## Браузер (`npm run dev`)

- [ ] Лента мест: поиск, фильтр по кухне, сортировка, сброс фильтров
- [ ] Добавление места с ленты и из формы визита
- [ ] Избранное: сердечко → экран «Избранное»
- [ ] Новый визит: валидация (ресторан, дата, блюда с оценками)
- [ ] Новый визит: фото (выбор файла), сохранение, превью на странице визита
- [ ] Страница места: счётчик визитов и рейтинг после сохранения визита
- [ ] Переход визит → `/visit/:id`, блюдо → `/dish/:id`
- [ ] Редактирование места (Изменить), удаление места с подтверждением
- [ ] Редактирование визита (дата/заметки/компаньоны), удаление визита
- [ ] Редактирование и удаление блюда
- [ ] F5: данные не пропадают
- [ ] Экспорт / импорт JSON на экране «Избранное»

## Android

- [ ] `npm run build:mobile` без ошибок
- [ ] `npm run cap:open:android` → Run на эмуляторе/устройстве
- [ ] Навигация по хеш-роутам работает
- [ ] Данные сохраняются после закрытия приложения
- [ ] Камера / галерея: добавить фото к визиту (разрешения)

## iOS (если добавлена платформа)

- [ ] CocoaPods установлен, `npm run cap:add:ios` / `build:mobile`
- [ ] Info.plist: тексты для Camera / Photo Library
- [ ] Запуск в симуляторе, офлайн-данные и фото
